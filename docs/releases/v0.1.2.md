# DSH Context Manager v0.1.2

首个公开版本：在 DeepSeek Harness 中查找、选择、压缩、排除与导入上下文。

## 中文

- Ctrl+F / Cmd+F 查找完整有效上下文，支持匹配导航、关键词高亮和手动选择压缩范围。
- 起点、终点和中间记录持续高亮，工具调用与结果保持配对。
- 摘要预览可编辑，确认后应用；范围排除无需调用模型。
- 从其他对话导入全部有效文本或连续范围；支持容量检查、超限压缩和分块摘要。
- 已应用内容通过 DSH 原生事件持久化，原始日志保留。

已验证 **DSH 0.2.1-rc.2**；源码开发需要 **Node.js 24+**。35 项自动测试通过，并完成真实安装包、重启恢复及后续模型请求验证。真实模型摘要质量未用付费提供方测试。

下载下方 `.tgz`；独立 Web profile 可执行：

```powershell
dsh plugin --profile web add ".\ningtian-byte-dsh-context-manager-0.1.2.tgz"
```

桌面版使用内置插件管理器。更新后重启或重新加载 DSH，打开会话的「上下文」标签页。`SHA256SUMS.txt` 提供安装包校验值。

[完整中文说明](https://github.com/NingTiAn-byte/DSH-context-manager/blob/main/README.md)

## English

First public release: find, select, summarize, exclude, and import conversation context in DeepSeek Harness.

- Full-text find with Ctrl+F / Cmd+F, match navigation, keyword highlighting, and manual selection for summarization.
- Continuous highlighting of start, end, and intermediate records; paired tool history stays intact.
- Editable summary previews with explicit apply; exclusion requires no model calls.
- Cross-conversation imports of all active text or a selected range, with capacity checks and chunked compression.
- Native DSH persistence with original event logs retained.

Verified with **DSH 0.2.1-rc.2**; source development requires **Node.js 24+**. All 35 automated tests pass, alongside real package loading, restart, and subsequent-request checks. Paid-provider summary quality has not been evaluated.

Download the `.tgz` below and use the command above for a standalone Web profile. Use the built-in plugin manager for Desktop, then restart or reload DSH. `SHA256SUMS.txt` contains the package checksum.
